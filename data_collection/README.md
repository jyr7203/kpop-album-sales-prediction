# FNC 앨범 유튜브 티저 데이터 수집 자동화 (n8n)

K-pop 아이돌 컴백 초동 판매량 예측 프로젝트("FNC 프로젝트")의 피처 데이터 중,
**앨범별 유튜브 티저 영상의 조회수 / 댓글 수 / 좋아요 수**를 수집하는 과정을
n8n 워크플로우로 재구성한 것입니다. 원본 프로젝트에서는 이 과정을 수작업으로
진행했고, 이 저장소는 그 작업을 이후에 n8n으로 자동화해 본 결과물입니다.

`workflow/fnc_youtube_teaser_collector_csv.json`은 실제로 로컬 n8n에서 끝까지
실행해 결과를 확인한 워크플로우를 그대로 내보낸 것입니다 (경로만 일반화).

## 배경 및 목적

- 대상 데이터: `그룹명` 컬럼에 있는 39개 그룹 전체의 앨범 중 **2019.12 ~ 2026.06**에
  발매된 앨범 (총 252건, `data/input.csv` 참고)
- 참고: 원본 데이터에는 "직전 초동 판매량"(한터차트 기준) 컬럼도 있지만, 이
  값이 없는 앨범(데뷔 초반이라 비교할 이전 앨범이 없는 경우 등)도 있어 이
  컬럼 자체로 필터링하면 9개 그룹이 통째로 빠지게 됩니다. 그룹을 빠짐없이
  포함하기 위해 **발매일 기준으로만 필터링**했고, `직전_초동_판매량`은 값이
  없는 경우 빈 칸으로 둡니다.
- 목적: 각 앨범의 공식 티저 영상을 찾아 조회수 / 댓글 수 / 좋아요 수를
  자동으로 수집하여, 초동 판매량 예측 모델의 입력 피처로 사용
- 원래는 앨범마다 유튜브에서 직접 티저 영상을 검색하고 수치를 기록했으나,
  이 과정을 **YouTube Data API v3 + n8n**으로 자동화

## 워크플로우 구조

```
수동 실행
  └─ 입력 CSV (로컬 데이터) 읽기
      └─ CSV 파싱
          └─ 앨범 발매일 필터 (2019-12-01~2026-06-30)
              └─ 1건씩 처리 (Loop Over Items)
                  ├─ 유튜브 티저 영상 검색 (YouTube Data API search.list)
                  │    └─ 가장 적합한 영상 선택 (제목에 teaser/티저 포함 + 발매일과
                  │         가장 가까운 공개일 기준으로 매칭, Code 노드)
                  │        └─ 영상 발견?
                  │             ├─ Yes → 유튜브 통계 조회 (videos.list statistics)
                  │             │           └─ 조회수/좋아요/댓글수 정리
                  │             └─ No  → 영상 없음 처리 (결측값 처리)
                  │                        └─ 호출 간격 대기 (API 쿼터 보호) → 다음 앨범으로 반복
                  └─ (전체 처리 완료) → 결과 CSV 변환 → 결과 CSV 저장
```

두 가지 버전으로 제공합니다.

- [`workflow/fnc_youtube_teaser_collector_csv.json`](workflow/fnc_youtube_teaser_collector_csv.json) — **로컬 CSV 파일**로 입출력하는 버전. 실제로 끝까지 실행 검증한 버전입니다.
- [`workflow/fnc_youtube_teaser_collector.json`](workflow/fnc_youtube_teaser_collector.json) — 입출력을 **Google Sheets**로 하는 버전 (구글 계정 OAuth 연결 필요, 참고용 초안)

## 핵심 로직

1. **입력**: 로컬 CSV(`그룹명 / 앨범명 / 발매일 / 직전_초동_판매량`)를 읽어서 파싱
2. **필터링**: 발매일이 2019-12-01 ~ 2026-06-30 범위인 행만 통과시킴
3. **영상 검색**: `{그룹명} {앨범명} teaser`로 YouTube 검색 API를 호출하고,
   `publishedBefore`를 발매일 기준 ISO 8601 형식(`YYYY-MM-DDT00:00:00.000Z`)으로
   제한해 실제 발매 전 공개된 티저만 대상으로 함
4. **영상 선택**: 검색 결과 중 제목에 `teaser`/`티저`가 포함된 영상을 우선
   후보로 삼고, 그중 발매일과 공개일 차이가 가장 작은 영상을 선택 (Code 노드)
5. **통계 수집**: 선택된 영상의 `viewCount`, `likeCount`, `commentCount`를
   `videos.list`로 조회 (좋아요/댓글이 비공개인 영상은 null 처리)
6. **결과 저장**: 전체 앨범 처리가 끝난 뒤 결과를 한 번에 CSV로 저장
   (중간에 실패하면 그때까지의 결과는 저장되지 않으므로, 배치를 API
   일일 쿼터 안에서 나누는 것이 중요합니다 — 아래 참고)
7. **속도 제어**: 각 앨범 처리 후 Wait 노드로 대기하여 rate limit을 피함

## 실행하면서 확인된 제약 사항 (직접 실행하며 겪은 이슈)

- **YouTube Data API 하루 검색 쿼터는 100건**입니다 (`search.list` 기준, 프로젝트
  전체 10,000 units와는 별개로 검색에만 걸린 하위 쿼터). 252건을 한 번에 돌리면
  중간에 반드시 막히므로, **하루 80건 정도로 나눠서** 여러 날에 걸쳐 실행해야
  합니다. 쿼터는 태평양시간(PT) 자정, 한국시간 기준 대략 오후 4시경 초기화됩니다.
- 결과가 마지막에 한 번에 저장되는 구조라, **쿼터 초과 등으로 중간에 실행이
  실패하면 그 배치는 처음부터 다시 돌려야 합니다.**
- n8n의 "Read/Write Files from Disk" 노드는 보안상 기본적으로 `~/.n8n-files`
  폴더로만 파일 접근이 제한됩니다. 입출력 CSV는 이 폴더 안에 두어야 합니다.
- CSV를 엑셀에서 편집 후 저장하면 인코딩이 UTF-8이 아닌 ANSI(CP949)로 바뀌면서
  한글 헤더가 깨질 수 있습니다. 메모장으로 편집 시 "UTF-8"로, 엑셀은
  "CSV UTF-8(쉼표로 분리)" 형식으로 저장해야 합니다.
- YouTube API의 `publishedBefore` 파라미터는 단순 날짜(`2025-10-13`)가 아니라
  RFC3339 형식(`2025-10-13T00:00:00Z`)을 요구합니다.

## 사용 방법 (CSV 버전)

1. n8n에서 `workflow/fnc_youtube_teaser_collector_csv.json`을 Import
2. `data/input.csv`를 `~/.n8n-files/input.csv` 위치에 저장 (또는 "입력 CSV
   (로컬 데이터) 읽기" 노드의 `fileSelector` 값을 원하는 경로로 수정)
3. **HTTP Query Auth** Credential 연결 (Name: `key`, Value: YouTube Data API v3 키) —
   "유튜브 티저 영상 검색", "유튜브 통계 조회" 두 노드에 동일하게 연결
4. "결과 CSV 저장" 노드의 저장 경로도 같은 방식으로 `~/.n8n-files/output.csv`로 확인
5. 하루 처리량을 80건 이내로 맞춰 `input.csv`를 나눠 여러 날에 걸쳐 실행

## 데이터 예시

- 입력 예시: [`data/input.csv`](data/input.csv) — 발매일 필터를 통과한 39개
  그룹 전체, 252개 앨범 목록 (그룹명, 앨범명, 발매일, 직전_초동_판매량 — 값이
  없는 경우 빈 칸)
- 출력 예시: [`data/sample_output.csv`](data/sample_output.csv) — 실제 수집된
  유튜브 티저 조회수/댓글수/좋아요수 샘플 15건

> 실제 API 키 등 민감 정보는 포함되어 있지 않으며, 워크플로우 파일의 로컬
> 경로는 `<사용자명>`으로 일반화했습니다. 샘플 CSV는 최종 예측 모델 학습에
> 사용했던 데이터셋의 일부를 재현용으로 정리한 것입니다.

## 사용 기술

- [n8n](https://n8n.io/) — 워크플로우 오케스트레이션 (로컬 self-hosted, Node.js 20 LTS)
- YouTube Data API v3 (`search.list`, `videos.list`)

## 자기소개서 등에 활용 시 참고

이 저장소는 원 프로젝트에서 수작업으로 진행했던 유튜브 티저 지표 수집 과정을
n8n으로 자동화해 재구성한 예시입니다. 실제 이력서/자기소개서에 서술할 때는
"수작업으로 했던 데이터 수집을 n8n으로 자동화해 보았다"는 사실 관계를
정확히 표현하는 것을 권장드립니다.
